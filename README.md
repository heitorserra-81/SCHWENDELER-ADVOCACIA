# Schwendler Advocacia Internacional — site conceito 1

Protótipo estático para avaliação, criado por Heitor Serra Neto (99Freelas).

## Publicar gratuitamente no GitHub Pages
1. Crie um repositório no GitHub e envie **o conteúdo da pasta `schwendler-site`** (o arquivo `index.html` deve ficar na raiz do repositório).
2. Em **Settings > Pages**, escolha **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
3. Aguarde a publicação e abra a URL indicada no GitHub Pages.

Não requer npm, build, terminal nem backend. Também abre diretamente clicando em `index.html`.

## O que está incluído
- Layout responsivo desktop/celular, menus, rolagem animada e efeito de profundidade CSS na imagem.
- Logotipo/monograma SVG autorais inspirados no primeiro conceito visual.
- Alternância PT/EN/FR/ES; textos provisórios devem ser revisados por tradutor/advogado antes da publicação definitiva.
- 6 áreas de atuação, formulário validado, botão flutuante para contato, animações e rodapé com crédito dourado animado.
- Imagem do advogado é **ilustrativa**, não representa a pessoa real. Substituir pela foto fornecida pelo cliente.

## Pontos pendentes antes de colocar no ar como site oficial
- Nome, OAB, biografia e dados verificados do advogado.
- E-mail/WhatsApp reais, aviso de privacidade e adequação jurídica; **o formulário é DEMONSTRATIVO, não envia mensagens**, mas pode copiar o texto preenchido.
- Revisão dos textos profissionais e traduções e das regras de publicidade da OAB.
- Substituir retrato ilustrativo por retrato autorizado do titular.

## Arquivos
- `index.html`: conteúdo do site.
- `assets/css/style.css`: design, responsividade e animações.
- `assets/js/main.js`: idiomas, menus, serviços e formulário.
- `assets/img/logo.svg` e `monograma.svg`: identidade visual.
- `assets/img/advogado-ilustrativo.webp`: foto ilustrativa derivada da proposta conceitual.
- `assets/img/conceito-referencia.webp`: imagem de referência da proposta (não utilizada pelo site).
